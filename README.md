Exploratory Data Analysis (EDA) on a Netflix movie dataset to uncover insights about genre popularity, trends, and movie ratings using Python libraries.

---

## 📁 Project Structure

Netflix_data_analysis/ ├── Movie_data_analysis.ipynb # Jupyter Notebook with EDA ├── mymoviedb.csv # Dataset file ├── requirements.txt # Required Python libraries └── README.md # Project documentation

---

## 📊 Dataset
- **File:** `mymoviedb.csv`
- Contains metadata of Netflix movies including:
  - Title
  - Genre(s)
  - Popularity score
  - Vote count
  - Release year

---

## 🔍 Key Findings

| Question | Insight |
|---------|---------|
| 🎭 Most frequent genre | **Drama** (14% of dataset) |
| 🗳️ Genre with highest votes | **Drama** again (18.5% of popular vote movies) |
| 🔝 Most popular movie | *Spider-Man: No Way Home* (Action, Adventure, Sci-Fi) |
| 📉 Least popular movie | *The United States, Thread* (Music, Drama, War, Sci-Fi, History) |
| 🗓️ Most active year | **2020** had the most films |
